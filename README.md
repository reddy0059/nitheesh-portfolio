# Nitheesh Maramreddy | Data Center Operations Portfolio

Personal portfolio website highlighting hands-on server and rack testing, Linux, MobaXterm, automated validation scripts, technical diagnostics, Jira documentation, and selected software projects.

## View the website

https://reddy0059.github.io/nitheesh-portfolio/

## What's included

- `index.html` - responsive, single-file portfolio site
- `resume.pdf` - updated resume for recruiters (contains contact information)
- `README.md` - repository description

## About the technical content

The troubleshooting workflow describes test failure investigation, diagnostics, documentation and escalation. It intentionally does **not** claim server component replacements or hardware repairs. Proprietary internal tools are described generically.

## Deployment

Upload these files to the **root** of the `main` branch in `reddy0059/nitheesh-portfolio`. GitHub Pages should use **Deploy from a branch -> main -> /(root)**. Replace both `index.html` and `resume.pdf` when updating the site.

## Privacy

The resume includes a public email and phone number. Remove or replace that information before uploading if you prefer not to publish it.
